# Happening Intelligence

Open-source software and scripts from Happening Intelligence, the team behind HappeningIQ.

## First project: AI-assisted observability

We're exploring how AI can help operators spot emerging issues in noisy
observability data. The goal is to group related signals from logs, metrics,
and traces, explain what changed, and point operators to the evidence they
need to investigate.

## Project status

We're defining the first prototype. If you've dealt with an issue that was
easy to miss in a flood of telemetry, open a GitHub issue and share what
signal would have helped you catch it earlier.
